# House Prices — Tidymodels Tour

A pedagogical, end-to-end walk through the Kaggle
[Housing Prices Competition for Kaggle Learn Users](https://www.kaggle.com/competitions/home-data-for-ml-course)
(the Ames, Iowa dataset), worked in R with [tidymodels](https://www.tidymodels.org/)
and rendered as a Quarto website. The regression companion to the
[Titanic tour](https://www.kaggle.com/competitions/titanic).

## What's here

- **Six model families** on one shared feature recipe — XGBoost, Random Forest,
  Neural Net (nnet), Elastic Net (glmnet), SVM (kernlab), MARS (earth) — plus a
  **stacked ensemble** (`stacks`).
- **Two-stage features:** `R/03_engineer.R` does the deterministic up-front work
  (recode Ames' "NA means absent" columns to `None`/`0`, derive `TotalSF`,
  `HouseAge`, bath/porch totals, `Has*`/`Is*` flags); `R/02_features.R`
  (`make_recipe()`) does the per-fold work (impute, Yeo-Johnson, dummy,
  normalize, PCA).
- **Model the log price.** Kaggle scores RMSE on `log(SalePrice)`, so every model
  trains on the log scale and the submission doc exponentiates back to dollars —
  CV `rmse` is directly comparable to the leaderboard.
- **Reproducible:** `renv` lockfile, `set.seed(42)`, seeded folds, `here::here()`
  paths, `freeze: auto`.

## Quick start

```r
renv::restore()      # install pinned packages (fast via the renv cache)
```

```bash
quarto render        # engineer data -> fit + tune every model -> build the site
```

Then open `_site/index.html`.

## Build a submission

```bash
quarto render docs/submission.qmd -P model:xgboost   # or rf, nnet, elasticnet, svm, mars, stack
kaggle competitions submit -c home-data-for-ml-course -f models/submission_xgboost.csv -m "xgboost baseline"
```

See `docs/setup-kaggle.md` for authenticating the Kaggle CLI.

## Layout

```
R/            00_setup, 01_eda, 02_features (recipe), 03_engineer (pre-render)
docs/         EDA + 6 model docs + stack + parameterized submission + kaggle setup
data/raw/     committed Ames CSVs + data_description.txt
data/processed/  engineered CSVs (regenerated by 03_engineer.R)
models/       *_res.rds (tuning), *_fit.rds (fitted), submission_*.csv
index.qmd     master document + auto-updating CV results table
```
