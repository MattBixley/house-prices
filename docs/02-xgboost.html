Gradient-boosted trees, the Kaggle workhorse

Where we are: First of six model documents in the House Prices — Tidymodels Tour. All six follow the same structure — recipe → spec → workflow → tune → finalize → evaluate → save — so once you’ve read this one, the others are quick to skim for the differences. The features come from the EDA and the shared make_recipe(). Remember the project-wide convention: we model log(SalePrice), because Kaggle scores this competition as RMSE on the log scale (see the master document).

Why XGBoost first?

Gradient-boosted decision trees are the default first reach on tabular Kaggle problems. They handle mixed numeric/categorical features, capture interactions (quality × size, neighborhood × age) automatically, are robust to monotone transforms, and tune to strong accuracy with modest effort. We tune four of the most impactful knobs.

The workflow

A workflow bundles the recipe and the model so resampling applies the exact same preprocessing to every fold — no leakage.

Show code 
xgb_wf <- workflow() |>
  add_recipe(xgb_recipe) |>

# Predictors used to finalize data-dependent params (num_comp upper bound).
preds <- prep(make_recipe(train, num_comp = 2)) |>

xgb_params <- extract_parameter_set_dials(xgb_wf) |>

set.seed(42)

Cross-validated performance

The fairest estimate of out-of-sample skill is the CV score of the chosen configuration — not the fit on the full training data (which overfits by construction).

collect_metrics(xgb_tuned) |>

## Tuning with 10-fold cross-validation

```{r}
#| label: resamples
# Stratify on the (log) outcome so each fold spans the full price range.
set.seed(42)
folds <- vfold_cv(train, v = 10, strata = SalePrice)
```

```{r}
#| label: grid
# Predictors used to finalize data-dependent params (num_comp upper bound).
preds <- prep(make_recipe(train, num_comp = 2)) |>
  bake(new_data = NULL) |>
  select(-SalePrice, -Id)

xgb_params <- extract_parameter_set_dials(xgb_wf) |>
  finalize(preds) |>
  update(num_comp = num_comp(range = c(2L, 15L)))

set.seed(42)
xgb_grid <- grid_space_filling(xgb_params, size = 20)
```

```{r}
#| label: tune
#| message: false
#| warning: false

# Score every candidate on RMSE (the competition metric on the log scale) and
# R-squared (interpretable goodness-of-fit).
xgb_metrics <- metric_set(rmse, rsq)

set.seed(42)
xgb_tuned <- tune_grid(
  xgb_wf,
  resamples = folds,
  grid      = xgb_grid,
  metrics   = xgb_metrics,
  control   = control_grid(save_pred = TRUE, save_workflow = TRUE)
)
```

