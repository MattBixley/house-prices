A small single-hidden-layer MLP via nnet

Where we are: Third of six model documents in the House Prices — Tidymodels Tour. Same structure as the others; we model log(SalePrice) and score on RMSE. The neural net is the model that most needs the recipe’s step_normalize() + step_pca() — MLPs are sensitive to input scale in a way tree ensembles are not.

Why a neural net here?

A single-hidden-layer MLP learns a smooth nonlinear function of the (normalized, decorrelated) principal components. On a well-featured tabular problem it rarely beats gradient boosting, but it makes different errors — which is exactly what makes it a valuable member of the stacked ensemble later.

Recipe, spec, workflow

The shared recipe already normalizes all numeric predictors and appends PCs, so the MLP sees well-behaved inputs. We tune the hidden-layer width and the weight decay penalty, and lean on num_comp to control input dimensionality.

Show code 
nnet_recipe <- make_recipe(train)

nnet_spec <- mlp(
  hidden_units = tune(),
  penalty      = tune(),
  epochs       = 300
) |>
  # MaxNWts must be large enough for (many predictors) x (hidden units); trace
  # off to keep the tuning log quiet. linout is set automatically in regression.
  set_engine("nnet", MaxNWts = 10000, trace = FALSE) |>
  set_mode("regression")

nnet_wf <- workflow() |>
  add_recipe(nnet_recipe) |>
  add_model(nnet_spec)

## Why a neural net here?

A single-hidden-layer MLP learns a smooth nonlinear function of the (normalized,
decorrelated) principal components. On a well-featured tabular problem it rarely
beats gradient boosting, but it makes *different* errors — which is exactly what
makes it a valuable member of the [stacked ensemble](05-stack.qmd) later.

## Recipe, spec, workflow

The shared recipe already normalizes all numeric predictors and appends PCs, so
the MLP sees well-behaved inputs. We tune the hidden-layer width and the weight
decay `penalty`, and lean on `num_comp` to control input dimensionality.

```{r}
#| label: recipe-spec
nnet_recipe <- make_recipe(train)

nnet_spec <- mlp(
  hidden_units = tune(),
  penalty      = tune(),
  epochs       = 300
) |>
  # MaxNWts must be large enough for (many predictors) x (hidden units); trace
  # off to keep the tuning log quiet. linout is set automatically in regression.
  set_engine("nnet", MaxNWts = 10000, trace = FALSE) |>
  set_mode("regression")

nnet_wf <- workflow() |>
  add_recipe(nnet_recipe) |>
  add_model(nnet_spec)
```

## Tuning with 10-fold cross-validation

```{r}
#| label: resamples
set.seed(42)
folds <- vfold_cv(train, v = 10, strata = SalePrice)
```

```{r}
#| label: grid
preds <- prep(make_recipe(train, num_comp = 2)) |>
  bake(new_data = NULL) |>
  select(-SalePrice, -Id)

nnet_params <- extract_parameter_set_dials(nnet_wf) |>
  finalize(preds) |>
  update(
    hidden_units = hidden_units(range = c(2L, 15L)),
    num_comp     = num_comp(range = c(2L, 15L))
  )

set.seed(42)
nnet_grid <- grid_space_filling(nnet_params, size = 20)
```

```{r}
#| label: tune
#| message: false
#| warning: false
nnet_metrics <- metric_set(rmse, rsq)

set.seed(42)
nnet_tuned <- tune_grid(
  nnet_wf,
  resamples = folds,
  grid      = nnet_grid,
  metrics   = nnet_metrics,
  control   = control_grid(save_pred = TRUE, save_workflow = TRUE)
)

saveRDS(nnet_tuned, here("models", "nnet_res.rds"))
```
