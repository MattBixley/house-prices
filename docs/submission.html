Building a Kaggle Submission

  • Show All Code
  • Hide All Code
  • View Source

One parameterized document, seven models, leaderboard-ready CSVs

Where we are: The final stop on the House Prices — Tidymodels Tour. Each model document fits a workflow and saves it to models/<model>_fit.rds. This document is parameterized: tell it which model, and it loads that fit, predicts on the test set, exponentiates predictions back to dollars, and writes a Kaggle-ready CSV.

How to render this document per model

This .qmd has a model parameter (default "xgboost"). Override it on the command line with -P model:<value>:

quarto render docs/submission.qmd -P model:xgboost
quarto render docs/submission.qmd -P model:rf
quarto render docs/submission.qmd -P model:nnet
quarto render docs/submission.qmd -P model:elasticnet
quarto render docs/submission.qmd -P model:svm
quarto render docs/submission.qmd -P model:mars
quarto render docs/submission.qmd -P model:stack

Each render reads the matching models/<model>_fit.rds, writes models/submission_<model>.csv, and prints the exact upload command. You must have fitted (rendered) the corresponding model document first so the .rds exists.

Predict and assemble the submission

Show code 
# Every model was trained on log(SalePrice), so predictions are on the log
# scale. predict() runs the workflow's recipe on the test data, then the model.
preds <- predict(model_fit, new_data = test)

# Kaggle requires EXACTLY two columns: Id and SalePrice (in dollars). We
# exponentiate the log-scale prediction back to dollars.
submission <- tibble(
  Id        = test$Id,
  SalePrice = exp(preds$.pred)
)

# Sanity checks: right number of rows, positive prices, no missing predictions.
stopifnot(
  nrow(submission) == nrow(test),
  all(submission$SalePrice > 0),
  !anyNA(submission$SalePrice)
)

TipThe leaderboard metric

This competition is scored on RMSE between the log of the predicted and the log of the observed SalePrice. Because we train on log(SalePrice), each model’s CV rmse (on the master results table) is already in the same units as the leaderboard — a rare, satisfying alignment.
